How this simulation works

The phone sends the same webhook payload that the WhatsApp Business Cloud API sends, to POST /api/whatsapp/webhook. The engine scans the link for real, with the same rules as the network Guard, and answers with reply buttons.

Only WhatsApp's delivery is simulated. Setting WHATSAPP_TOKEN and WHATSAPP_PHONE_ID sends real replies through Meta's Graph API; that path has not been tested yet.
